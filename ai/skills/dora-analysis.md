# DORA Metrics Analysis

## Purpose

Interpret DORA metrics.

## Metrics

Deployment Frequency

Lead Time

Change Failure Rate

Mean Time To Recovery

## Analysis

For every metric:

Explain

Current value

Trend

Impact

Possible causes

Recommendation

## Rules

Do not explain DORA definitions if user only wants analysis.

Focus on trends.

Prioritize metrics with biggest deterioration.

Always mention relationships.

Example:

Low deployment frequency
↓

Higher lead time
↓

Delayed customer value
