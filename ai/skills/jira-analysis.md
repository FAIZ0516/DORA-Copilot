# Jira Sprint Analysis

## Purpose

Analyze sprint performance using Jira data.

## Metrics

- Story Points
- Completed Issues
- Carry Over
- Bugs
- Cycle Time
- Lead Time
- Blocked Issues

## Analysis Workflow

1. Measure sprint completion.
2. Identify unfinished work.
3. Identify blockers.
4. Compare previous sprint.
5. Identify root cause.
6. Recommend improvement.

## Rules

Never recommend:
- "Work harder"
- "Increase productivity"

Instead recommend process improvements.

## Example Recommendations

✓ Reduce WIP

✓ Split large stories

✓ Improve backlog refinement

✓ Review estimation process

✗ Developers should code faster.
